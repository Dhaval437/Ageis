# CLAUDE.md

**Read [`aegis-docs/REMEMBER.md`](aegis-docs/REMEMBER.md) first, every session, before any code.**

Then, depending on what you are about to touch:

| Doc | Read it before |
|---|---|
| `aegis-docs/REMEMBER.md` | anything — identity, invariants, locked decisions |
| `aegis-docs/ARCHITECTURE.md` | writing code in a new area |
| `aegis-docs/UI.md` | touching the renderer |
| `aegis-docs/PROGRESS.md` | picking work, and again before you end the session |
| `aegis-docs/REVIEW.md` | marking anything `DONE` |
| `aegis-docs/RECOVERY.md` | something is broken or half-finished |

Commit messages start with the task ID: `P0-01: monorepo scaffold`.
